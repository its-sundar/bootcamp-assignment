# Assignment 2 - Object-Oriented Programming (OOP) in Python

## Description
This assignment demonstrates the fundamental concepts of Object-Oriented Programming (OOP) in Python using simple examples.

## Topics Covered

### 1. Class and Object
A class is a blueprint for creating objects. An object is an instance of a class that contains data and methods.

### 2. Constructor
A constructor (`__init__`) is a special method that automatically initializes an object when it is created.

### 3. Inheritance
Inheritance allows a new class to inherit the properties and methods of an existing class, promoting code reuse.

### 4. Polymorphism
Polymorphism allows different classes to use the same method name while providing their own implementation.

### 5. Encapsulation
Encapsulation protects data by restricting direct access to it and providing controlled access through methods.

### 6. Abstraction
Abstraction hides implementation details and exposes only the essential features of an object.
